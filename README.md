# IPv6 Configuration Lab

A basic Cisco Packet Tracer lab demonstrating IPv6 addressing and routing between multiple networks.

## Topology

PC1 ---- Router ---- PC2

## IPv6 Addressing

| Device | IPv6 Address |
|----------|----------|
| Router Fa0/0 | 2001:DB8:0:1::1/64 |
| PC1 | 2001:DB8:0:1::2/64 |
| Router Fa0/1 | 2001:DB8:0:2::1/64 |
| PC2 | 2001:DB8:0:2::2/64 |

## Configuration Tasks

- Enable IPv6 routing
- Configure IPv6 addresses
- Configure default gateways
- Verify end-to-end connectivity

## Verification

Successful IPv6 communication between PC1 and PC2 using ping.

- IPv6 Addressing
- IPv6 Routing
- Cisco IOS Configuration
